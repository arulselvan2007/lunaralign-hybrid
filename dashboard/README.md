# LunarAlign-Hybrid Dashboard

Interactive Streamlit application for:
- Visualizing raw and sliced GeoTIFF tiles.
- Displaying CRS, GeoTransform, and lunar crater coordinates.
- Comparing multi-temporal satellite passes with side-by-side match visualizations (LightGlue / RoMa / MAGSAC+).

### Launching:
```bash
streamlit run app.py
```
